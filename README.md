# Titanic Survival Prediction

Predicts Titanic passenger survival using Logistic Regression and Random Forest.

- Cleaned data, engineered features (Title, FamilySize)
- Compared two models — Logistic Regression won (AUC 0.868 vs 0.834)
- Evaluated with precision, recall, F1, ROC-AUC

**Tools:** Python, pandas, scikit-learn, seaborn

**Data:** [Titanic dataset on Kaggle](https://www.kaggle.com/competitions/titanic/data) — download `train.csv` to run.
